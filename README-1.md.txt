# لوحة متابعة مؤشرات الأداء اليومية — ريتش لاند للصناعات الغذائية

لوحة عرض ومتابعة يومية لمؤشرات الأداء (KPIs) في المصنع: أربع جداول أقسام + أربع خطوط إنتاج + رسوم بيانية،
متزامنة مع جوجل شيت، بحسابات وصلاحيات محلية، وجاهزة للعرض على شاشة تلفزيون في المصنع.

---

## محتويات المشروع

| الملف | وظيفته | يترفع على GitHub؟ |
|---|---|---|
| `index.html` | اللوحة كاملة (HTML + CSS + JS في ملف واحد) — الصفحة الرئيسية | ✅ |
| `config.js` | إعدادات عامة (رابط الـ Web App فقط) — **من غير أي مفتاح** | ✅ |
| `apps-script.gs` | الواجهة الخلفية على جوجل شيت (بتتلصق في Apps Script، مش بتتنفّذ من الموقع) | ✅ |
| `404.html` | صفحة الروابط الغلط لـ GitHub Pages | ✅ |
| `.gitignore` | بيمنع رفع `config.local.js` وأي ملفات محلية | ✅ |
| `دليل-التشغيل.md` / `ملف-المشروع.md` | التشغيل والتوثيق | ✅ |

> **مفيش أي مفتاح أو باسورد في المستودع.** مفتاح الكتابة (`WRITE_KEY`) بيتكتب مرة واحدة من داخل اللوحة
> (**لوحة التحكم → ربط جوجل شيت**) وبيتخزن على الجهاز نفسه (localStorage). وكلمة مرور الأدمن الافتراضية
> متخزنة كبصمة جاهزة مش كنص.

## خطوات الرفع على GitHub وتشغيل GitHub Pages

### 1) إنشاء المستودع
1. ادخل [github.com/new](https://github.com/new).
2. **Repository name**: مثلاً `richland-kpi-dashboard`.
3. اختار **Public** (لازم Public عشان GitHub Pages المجاني)، أو **Private** لو هتستخدم Cloudflare Pages بدلها.
4. اضغط **Create repository**.

### 2) رفع الملفات

**الطريقة الأسهل (من غير أوامر):**
1. في المستودع الجديد اضغط **Add file → Upload files**.
2. اسحب الملفات: `index.html` و `config.js` و `404.html` و `.gitignore` و `apps-script.gs` وملفات التوثيق.
3. اكتب رسالة زي `أول نسخة من اللوحة` واضغط **Commit changes**.

**بالأوامر (Git):**
```bash
cd المجلد-اللي-فيه-الملفات
git init
git add .
git commit -m "أول نسخة من لوحة مؤشرات الأداء"
git branch -M main
git remote add origin https://github.com/USERNAME/richland-kpi-dashboard.git
git push -u origin main
```

### 3) تشغيل GitHub Pages
1. من المستودع: **Settings → Pages**.
2. تحت **Build and deployment → Source** اختار **Deploy from a branch**.
3. **Branch**: `main` &nbsp;•&nbsp; **Folder**: `/ (root)` → **Save**.
4. استنى دقيقة أو اتنين، وهيظهر لك الرابط النهائي فوق الصفحة:

```
https://USERNAME.github.io/richland-kpi-dashboard/
```

`index.html` هو الصفحة الرئيسية تلقائيًا، فالرابط ده بيفتح اللوحة على طول.

### 4) أي تعديل بعد كده
- **من الموقع:** افتح الملف في المستودع → أيقونة القلم → عدّل → **Commit changes**.
- **بالأوامر:**
  ```bash
  git add .
  git commit -m "وصف التعديل"
  git push
  ```
GitHub Pages بيحدّث الموقع لوحده خلال دقيقة تقريبًا. لو مالقيتش التغيير، اعمل **Ctrl + Shift + R** لتفريغ الكاش.

### 5) بعد أول نشر
1. افتح رابط الموقع.
2. **لوحة التحكم → تسجيل الدخول** بحساب الأدمن (بياناته في `دليل-التشغيل.md`) وغيّر كلمة المرور فورًا.
3. **ربط جوجل شيت** → الصق رابط الـ Web App و **مفتاح الكتابة** → اتصال ومزامنة.

> **ملاحظة:** لازم الموقع يشتغل على `https` (وده اللي بيعمله GitHub Pages) عشان بصمة كلمة المرور تشتغل بأقوى صورة.

### بديل للمستودع الخاص
لو عايز المستودع **Private**: استخدم **Cloudflare Pages** أو **Netlify** — الاتنين بيربطوا بمستودع خاص ويدوك رابط ثابت وHTTPS مجانًا،
واختار Build command: (فاضي) و Output directory: `/`.

## الإعداد المطلوب في Apps Script

بالتفصيل في `دليل-التشغيل.md`، والملخص:

1. جوجل شيت جديد → **Extensions → Apps Script** → الصق `apps-script.gs`.
2. غيّر `WRITE_KEY` لقيمة عشوائية طويلة، وحطّ **نفس القيمة** في اللوحة من "ربط جوجل شيت".
3. شغّل `setup` مرة واحدة (بيعمل كل التبويبات)، ثم `setupTriggers` مرة واحدة (التجميع اليومي).
4. **Deploy → New deployment → Web app** — Execute as: **Me**، Who has access: **Anyone** → انسخ رابط `/exec`.
5. أي تعديل في الكود بعد كده لازم **Deploy → Manage deployments → New version → Deploy**.

## الأعمدة والتبويبات في جوجل شيت

| التبويب | الوصف |
|---|---|
| `Data` | القيم الحالية لكل مؤشر |
| `Meta` | التاريخ والوردية والرسالة ومعادلة الأداء ومواعيد الورديات |
| `Users` | الحسابات والصلاحيات (بصمات كلمات المرور) |
| `Log` | صف مستقل لكل (تاريخ × وردية × مؤشر) |
| `Daily` | ملخص كل يوم |
| `Monthly` | ملخص كل شهر + نسبة الالتزام والاتجاه |
| `History` | نقاط الرسوم البيانية |
| `Audit` | مين غيّر إيه وإمتى |

**الأعمدة المضافة في النسخة الحالية (متوافقة مع الشيتات القديمة — بتتضاف لوحدها من غير ما تلمس القديم):**

| التبويب | العمود الجديد | الوصف |
|---|---|---|
| `Data` | `badge` | `show` أو `hide` — إظهار/إخفاء وسام الأداء للمؤشر (الافتراضي `show`) |
| `Data` | `name` | اسم المؤشر القابل للتعديل (موجود من قبل، وبقى بيتحدّث من اللوحة) |
| `Users` | `hashAlt` | بصمة بديلة لكلمة المرور (للتوافق مع فتح الملف بـ `file://`) |
